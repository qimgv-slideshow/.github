# qimgv - A Fast Look at Pictures You May Open

qimgv is a viewer. You open a directory, step through frames, and leave the files as they were. It does not retouch, and it does not include a library of images.

---

## Product Snapshot

The window is meant to be quick: next image, previous image, zoom. A slideshow plays that folder. Use it for a review, not for a batch convert. If a setting writes on exit, turn that off until you have seen one file survive a close with the same date in Explorer.

Stay inside the folder you chose. Do not open a path on a shared drive just because it is visible. Private pictures should not stay on screen when you leave the desk. qimgv will not remove a mark you did not put on the photo.

## Highlights

- A folder you select
- Next and previous
- Zoom to the pixels
- A slideshow of those files
- Close without a new file date
- No convert unless you explicitly save a copy

---

## Live Production

Use it to flip through a shoot you copied off a card. Pick what you will edit elsewhere. Do not delete from qimgv until you know the delete path and you have a backup. The card stays full until the computer copy has been opened.

A cache makes the second look faster. Clearing it does not delete photos. If the viewer feels like it edited a file, check the timestamp and restore the original.

---

## The Time in Explorer

After you close qimgv, the photo's modified time should be the old one. If it is new, something saved. Restore the picture from the card or the backup before you open the folder again.

---

## Setup Path

Prerequisites: A folder of images you may view.

1. Install qimgv and open that folder.
2. Open one picture and zoom in.
3. Step forward and back.
4. Close the window.
5. Confirm in Explorer that the file time is unchanged.

## Who Benefits

qimgv fits a fast review of your own pictures. It does not fit an overwrite, a folder you should not open, or a delete from a card you have not copied.

---

## Fixes

The photo looks soft: you are zoomed to fit. Switch to actual size. The date changed: you saved. Restore the copy. The folder is wrong: close it and open the directory you meant. A file will not preview: open it in the program that created it, if you may.
